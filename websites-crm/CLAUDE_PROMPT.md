# Websites CRM — Claude build prompt

Copy the prompt below into Claude to generate the CRM application in this folder.

---

Build a polished, responsive CRM web app for managing website clients and projects.

## Stack and deployment
- Use Next.js with TypeScript and Tailwind CSS.
- Structure the project for deployment on Vercel.
- Keep the app self-contained. Do not require paid services or API keys.
- Use realistic demo data. If persistence is needed, use local storage and document how to replace it with a database later.

## Features
- Dashboard with client, active project, task, and revenue summary cards.
- Client list with search, filters, status, contact details, and notes.
- Client detail pages showing projects, activity, and contact information.
- Project tracking with status, deadlines, budgets, and assigned team members.
- Task management with priority, due date, and completion status.
- A simple activity feed.
- Responsive navigation, accessible controls, and useful empty states.

## Design
Create a cohesive, professional interface suitable for a small web agency. Make the information easy to scan and keep the layout usable on mobile and desktop. Populate the UI with believable demo content so it looks complete on first launch.

## Deliverables
Create a complete runnable project in this folder, including all source files, package.json, a suitable .gitignore, and a README with local setup and Vercel deployment instructions. Check the app builds successfully and fix build errors. In your final response, list the files created and the exact commands to run the app locally.
