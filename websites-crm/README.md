# Websites CRM

This folder contains the build brief for the Websites CRM application.

## Build the app with Claude

Open [CLAUDE_PROMPT.md](./CLAUDE_PROMPT.md), copy its contents, and ask Claude to generate the complete app in this folder. Once Claude has created the project files, you can send them back here and I can help add them to GitHub.

## Deploy with Vercel

After the app files are in this folder:

1. Import this GitHub repository into Vercel.
2. Set the project root directory to `websites-crm`.
3. Keep the framework preset as Next.js and deploy.
4. Connect the GitHub repository in Vercel so pushes to the selected branch trigger deployments.

The CRM app itself has not been generated yet; the prompt describes the requested features and setup.
